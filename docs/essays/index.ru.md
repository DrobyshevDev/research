# Эссе

Один вопрос по нескольким статьям, когда одного разбора не хватает, чтобы
удержать рассуждение.

Эссе разрешено занимать позицию, которую разбору занимать нельзя. Источники оно
называет так же и так же говорит, что изменит его вывод. Разница в том, что
вывод здесь принадлежит автору, а не литературе.
